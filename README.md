# INNOE — демонстраційний прототип магазину

Мінімальний робочий прототип інтернет-магазину одягу, взуття та аксесуарів. Потрібен, щоб локально подивитися дизайн і пройти основні сценарії. Це не робочий магазин.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

Перевірка типів, лінтера і збірки:

```bash
npx tsc --noEmit
npm run lint
npm run build
```

## Що можна зробити

- Переглянути головну, каталог, картку речі, кошик і демонстраційне оформлення.
- Шукати серед демонстраційних товарів.
- Фільтрувати за категорією, розміром, кольором і ціною, змінювати сортування.
- Обрати розмір і колір, додати річ до кошика, змінити кількість і видалити позицію.
- Заповнити форму оформлення й побачити підтвердження. Дані нікуди не відправляються.

Кошик зберігається в `localStorage` цього браузера.

## Обмеження

- Немає бекенда, бази, авторизації, реальної оплати, складу і служб доставки.
- Ціни, артикули, залишки й адреса на Рейтарській вигадані.
- Фотографії — стокові кадри, підібрані під конкретні моделі, а не зйомка бренду.
- Частина товарів має одне фото: галерея показує стільки кадрів, скільки є.
- Колір на фото — основний. Інші кольори змінюють варіант у формі, але не підміняють знімок.
- Сайт позначено `noindex`, щоб прототип не сприймався як публічний магазин.
